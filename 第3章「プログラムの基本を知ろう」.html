LESSON 7プログラムってなに？

プログラムとは、「pro（あらかじめ）」「gram（書かれたもの）」という意味があり、これから行うことをあらかじめ書いた「program（予定表）」のこと

🎻
演奏会のプログラム
これから演奏する曲の予定表
🏃
ダイエットのプログラム
これから行うダイエットの予定表
💻
コンピュータのプログラム

コンピュータは、プログラム（予定表）に書かれたとおりに、上から順番に仕事をこなしていきます。

LESSON 9文字列を使いこなそう

🔗 文字列をつなぐ

プログラム

出力結果

数どうしの「+」は足し算、文字列どうしの「+」はくっつける。同じ記号でも中身によって働きが変わります。

📏 文字数を調べる

文字列の文字数を調べるには、「len()」を使う

len(文字列)
プログラム 
w = "こんにちは。" + "私はパイソンです。"
print(len(w))
出力結果
  • lenは「length（長さ）」の略
  • 文字列だけではなく、リストの長さなども調べられる

✂️ 文字列の一部分を取り出す

文字列の中から一部分の文字を取り出すときは、[ ]（ブラケット）を使う

文字列[位置A] … 位置Aの1文字 文字列[位置A:位置B] … 位置Aから位置Bの直前までの範囲の文字列 文字列[:位置B] … 先頭から位置Bの直前までの範囲の文字列 文字列[位置A:] … 位置Aから末尾までの範囲の文字列
  • 指定する位置は「0から始まる番号」で指定
  • 先頭から「0」「1」「2」と割り当てられている
  • 「こんにちは。私はパイソンです。」という文字列は15文字なので「0～14」で指定
  • Pythonの特殊機能として、マイナスの値を使うと「末尾からの位置になる」という機能がある（末尾から3番目の文字を「-3」と指定することもできる）

先頭の「こ」と、途中にある「私はパイソン」と、末尾の「です。」を取り出す場合

w[0] → こw[6:12] → 私はパイソンw[-3:] → です。
青い数字が前からの位置（0から）、赤い数字が後ろからの位置（-1から）。
w[6:12] は「6番から、12番の直前（11番）まで」なので、12番の「で」は入りません。
プログラム 
w = "こんにちは。" + "私はパイソンです。"
print(w[0])
print(w[6:12])
print(w[-3:])
出力結果

↩️ 文字列の途中で改行する

改行コードは「\（バックスラッシュ）」に「n」と続けて「\n」と書く

プログラム 
w = "こんにちは。" + "\n" + "私はパイソンです。"
print(w)
出力結果
  • 長い文章のときなど、改行するたびにprint()が必要で、文字列を入れる変数もその分必要になるが、改行コードを使えば、1つの変数に改行も含めた複数行の文字列を入れて、1つのprint()だけで表示できる
  • 「\（バックスラッシュ）」記号は、IDLEやエディタの画面には「￥」と表示されるが、効果は同じ

LESSON 10データ型を変換しよう

「ユーザーの入力した文字列で計算したい場合」や「ネットからダウンロードした文字列で計算したい場合」などでは、データ型を意識する必要がある

int(文字列) … 文字列型を、整数型に変換する float(文字列) … 文字列型を、浮動小数点数型に変換する str(数値) … 整数型や浮動小数点数型を、文字列型に変換する

❌ 文字列と数はそのまま足せない

「文字列"100"と、整数23の足し算」をそのまま実行すると、エラーが表示される

プログラム 
a = "100"
print(a+23)
出力結果
" " で囲んだ "100" は、見た目は数でも中身は文字。Pythonは「文字と数をくっつけることはできません」と困ってしまいます。

これをint()を使って文字列を整数に変換してから計算すると正しく計算できる

プログラム 
a = "100"
print(int(a)+23)
出力結果

⚠️ 変換できないときはエラーになる

数値に変換するとき、変換できない文字列で行うとエラーになる

プログラム 
b = "こんにちは"
print(int(b)+23)
出力結果

このようなエラーが起こりそうなときは、あらかじめチェックしておくことで防ぐことができる。isdigit()という命令を使えば、「その変数は正しく数値に変換できるのか」をチェックすることができ、変換できるときはTrue、できないときはFalseが返ってくる。調べてTrueが返ってきたときだけ変換すればエラーにならない

チェックしたい変数.isdigit()
プログラム 
a = "100"
b = "こんにちは"
print(a.isdigit())
print(b.isdigit())
出力結果
  • "100"は整数に変換できる（True）が、"こんにちは"は整数に変換できない（False）ことがわかる

「"こんにちは"と、整数23の足し算をする」というプログラムを実行

（数値に変換できないときは「数値じゃないよ」と表示される　※エラーで終了しないように工夫することが大事）

プログラム 
b = "こんにちは"if b.isdigit():# 数に変換できるなら…    print(int(b)+23)else:# そうでなければ…    print("数値じゃないよ")
出力結果
  • 「こんにちは」は数値ではないため、「数値じゃないよ」と表示された
ここで使った if 〜 else は、LESSON 13 でくわしく学びます。

LESSON 12プログラムの3つの基本の形

プログラムは「順次」「分岐」「反復」の3つの組み合わせ

① 順次
上から順番に、実行する
② 分岐（if文）
もしも〜なら実行する
③ 反復（for文）
同じ処理を繰り返す
  • ①順次（上から順番に、実行する）
  • ②分岐（もしも～なら実行する）
    • 条件によって「処理をするかしないかの選択」を行ったり「場合分け」を行ったりする
    • Pythonでは、「if文」を使う
  • ③反復（同じ処理を繰り返す）
    • 「回数を指定した繰り返し」や「リストの要素をすべて調べる繰り返し」を行うことができる
    • 「for文」を使う
朝のしたくで例えると…「顔を洗う→着替える」が順次、「もしも雨なら傘を持つ」が分岐、「歯を10回みがく」が反復。どんなに大きなプログラムも、この3つの組み合わせでできています。

LESSON 13if文（もしも〜なら）

if文は、「もしも△△だったら」の部分と、「〇〇をする」の部分に分けて書く

if 条件式: 条件式が正しいときにする処理

⚖️ 2つの値を比較する記号：比較演算子

記号働き例（score が 80 のとき）
==左辺が右辺と同じscore == 80 → True
!=左辺が右辺と違うscore != 80 → False
<左辺が右辺より小さいscore < 80 → False
<=左辺が右辺以下score <= 80 → True
>左辺が右辺より大きいscore > 80 → False
>=左辺が右辺以上score >= 80 → True
「同じ」は = ではなく ==（イコール2つ）。= 1つは「箱に入れる」でしたね。
  • 「〇〇をする」の部分は、一段「インデント（字下げ）」して表現する
  • 複数行ある場合はそれらをすべてインデントする
  • Pythonでは「インデントしている部分」が「ひとまとまり」として扱われ、これを「ブロック」という
  • ブロックにするには行の先端に「タブ」または「半角スペース4文字」を入れる
  • IDLEで入力しているときは、自動的にタブが入力されてインデントされる

✏️ if文を試してみよう

もしもscoreが80点以上だったら、"やったね！次もこの調子だ"と表示され、80点より小さかったら何も表示されないプログラム

プログラム 
score = 90
if score >= 80:
    print("やったね！")
    print("次もこの調子だ")
出力結果
  • 「score >= 80」の条件だと、80ピッタリも含まれる（「score > 80」の条件では80は含まれない）

🔀 「そうでないとき」の処理を書く

if 条件式: 条件式が正しいときにする処理 else: 条件式が正しくないときにする処理

もしもscoreが80点以上だったら、"やったね！次もこの調子だ"と表示されて、そうでなかったら"残念でした"と表示されるプログラム

プログラム 
score = 60
if score >= 80:
    print("やったね！")
    print("次もこの調子だ")
else:
    print("残念でした")
出力結果

➕ 条件を追加する：elif

if文ではさらに条件を追加することもできる。

「もしも『条件A』だったら『処理1』をして、そうでない場合にもしも『条件B』だったら『処理2』をして、どちらでもない場合は『処理3』をする」という2つの条件によって3つの処理の分岐を行う。

「elif」を使うと条件を追加していくことができる。

if 条件式A: 条件式Aが正しいときにする処理1 elif 条件式B: 条件式Aが正しくなくて、条件式Bが正しいときにする処理2 else: どちらも正しくないときにする処理3
elif は「else if（そうでなくて、もしも）」を縮めた言葉です。上から順に条件を調べて、最初に当てはまったところだけが実行されます。
書式の最後につく「:（コロン）」は必ず半角で入力します。全角の「：」だとエラーになります。

LESSON 14for文（くり返し）

Pythonのfor文には、「回数を指定して繰り返すfor文」と「リストの要素について繰り返すfor文」の2種類がある。

🔢 回数を指定して繰り返すfor文

「回数を指定して繰り返すfor文」は、「回数」を決めて「繰り返す処理」を指示し、回数をカウントするための「カウント変数」も指定する。

for カウント変数 in range(回数): 繰り返す処理

5×0～5×9の10個の掛け算をするプログラム

繰り返す回数：0～9の10回、繰り返す処理：5かける、カウントの値と、その掛け算の答えを表示すること

プログラム 
for i in range(10):# i に 0,1,2,…,9 が順に入る    print(5,"×",i,"=",5*i)
出力結果
  • 掛け算が10行表示された
range(10) は「0から9までの10個の数」。0から数えるので、10は入らないことに注意。

📋 リストのすべての要素について繰り返すfor文

「リストのすべての要素について繰り返すfor文」は、「リスト」と「繰り返す処理」を指示し、リストから取り出した要素を一時的に入れて使うための「要素を入れる変数」も指定する。

for 要素を入れる変数 in リスト: 繰り返す処理
プログラム 
scorelist = [64, 100, 78, 80, 72]
for i in scorelist:
    print(i)
出力結果
  • リストから順番に表示された

➕ リストの中の点数を足すfor文

リストの中に入っている点数の合計を求めるプログラム

合計値を求めるため、合計値用変数（total）を用意して、あらかじめ0にリセットしておく。

「繰り返す処理」は、「リストから取り出した値を、合計値用変数に足すこと」

繰り返しが終わったら、total変数に合計値が求まるため表示、1回だけ行えばいいため、インデントのあとにインデントせずに行う

プログラム 
scorelist = [64, 100, 78, 80, 72]total = 0# 合計を入れる箱を0にしておくfor i in scorelist:    total = total + i# 今の合計に i を足して、箱に入れ直すprint(total)# インデントなし → くり返しが終わってから1回だけ
回目i（取り出した点数）total = total + i
1640 + 64 = 64
210064 + 100 = 164
378164 + 78 = 242
480242 + 80 = 322
572322 + 72 = 394
出力結果
  • 順番に次々と足されていき、最後に合計が表示される

🪆 for文の入れ子

for文の「繰り返す処理」のところに、さらにfor文を入れることもできる、「繰り返しの中で繰り返しを行う」という二重の繰り返しのことを、「for文の入れ子」という。

for カウント変数1 in range(回数): for カウント変数2 in range(回数): 繰り返す処理
  • for文の入れ子では、外側のfor文のカウントが1つ進むたびに、「内側のfor文がすべて繰り返し終わるまで繰り返す」
時計をイメージしてみましょう。短い針（外側のfor）が1つ進むあいだに、長い針（内側のfor）はぐるっと1周します。

0から9までの整数同士を掛け合わせるプログラム

「繰り返しの中で繰り返す」ため、内側のfor文の「繰り返す処理」はインデントが二段階になっている

プログラム 
for i in range(10):
    for j in range(10):
        print(j,"×",i,"=",j*i)
出力結果

10回 × 10回 ＝ 100行の掛け算が表示されます。

  • 「繰り返しの中で行う繰り返しの中で、さらに繰り返しを行う」こともできる
  • 「for文の入れ子」は、二重三重四重に重ねていくことができるが、その分繰り返しの量が多くなり、処理に時間がかかるようになる

LESSON 15関数とモジュール

「ある仕事を行う命令のまとまり」をブロックに書いてまとめたもの：関数（print()やint()など）

関数は「関数名」を決めて「def 関数名():」と指定し、「その関数で行う処理」を指示して作り、「関数名」は「この関数は何をするものなのか」をわかりやすく表現した名前をつける

「関数で行う処理」はまとまった処理のため、「ブロック」で作る

def 関数名(): 関数で行う処理
ブロックの前は必ず「:（コロン）」がつく

👋 関数を使ってみよう

「こんにちはと表示する関数」を作って、3回呼び出すプログラム

プログラム 
def sayhello():# 関数を作る（この時点ではまだ動かない）    print("こんにちは") sayhello()# 呼び出す（1回目）sayhello()# 呼び出す（2回目）sayhello()# 呼び出す（3回目）
出力結果

📨 引数を使って関数にデータを渡す

関数に引き渡すデータのこと：引数（ひきすう／パラメータ）

関数が処理したあと結果として戻ってくる値：戻り値（もどりち）

def 関数名(引数1, 引数2, ...): 関数で行う処理 return 戻り値
種類どんなときに使う？この章の例
① 引数も戻り値もない関数決まった仕事をさせたいときsayhello()
② 引数だけある関数違うデータを渡して、処理を調整したいときsayhello2(name)
③ 戻り値だけある関数結果に変化があるので知りたいときomikuji()
④ 引数も戻り値もある関数データを渡して計算するときや、実行結果を知りたいときpostTaxPrice(price)

🧾 消費税（10％）を計算してくれるプログラム

商品の本体価格を渡すと、消費税計算を行い、消費税込みの金額がわかる関数（④引数も戻り値もある関数）

商品の価格（price）を引数として渡すと、関数の中で10％の消費税計算を行い、税込み金額を戻り値として返す

関数は「postTaxPrice（本体価格）」

プログラム 
def postTaxPrice(price):# price に渡された価格が入る    ans = price * 1.1    return ans# 計算結果を返す print(postTaxPrice(120),"円")print(postTaxPrice(128),"円")print(postTaxPrice(980),"円")
出力結果
  • 「仕事を関数にまとめて書く」ということは、「プログラムの意味が分かりやすい」ことになり、それだけバグ（プログラムのエラー）が少なくなることにも繋がる

🎁 引数か戻り値だけの関数の使い道

ユーザー名つきで、こんにちはと表示する関数（②引数だけある関数）

📥 importで読み込む

import：別のファイルに書いた関数などのプログラムを読み込んで利用することができる

モジュール：importで読み込むプログラムファイルのこと

import モジュール名 … インポートする方法 モジュール名.関数名 … importしたモジュールの関数を実行する方法

🛠️ モジュールを作ってみよう

消費税（10％）を計算してくれるプログラムで作った、税込み金額を計算するプログラムを2つのファイルに分けます。1つ目のファイルには「モジュール」を作り、2つ目のファイルには「そのモジュールを読み込んで動かすプログラム」を書きます。

2つ目のファイルが tax.py を「借りて」使うイメージ

① モジュールを作る

  • IDLEの File メニュー → New File を選択して、1つ目のファイルを作る
  • このファイルには関数部分だけを書いて「モジュール」にする（tax.pyというファイル名で保存）
tax.py 
def postTaxPrice(price):
    ans = price * 1.1
    return ans

② モジュールを読み込んで動かすプログラムを作る

  • 再び、File メニュー → New File を選択して、2つ目のファイルを作る
  • 1つ目のファイルのモジュール名を指定して、importで読み込む
  • 関数を呼び出すときは、「モジュール名.関数名」で指定する（taxというモジュールの中のpostTaxPrice関数なので、「tax.postTaxPrice」と指定する）
2つ目のファイル 
import tax

print(tax.postTaxPrice(120),"円")
print(tax.postTaxPrice(128),"円")
print(tax.postTaxPrice(980),"円")
出力結果
  • importで読み込んでいるため、つながって動いている
2つのファイルは同じフォルダに保存しておきましょう。import するときは「.py」を付けずに import tax と書きます。

📚 用意されたモジュールをimportする

  • 数値計算に使う「math」「random」、日付や時刻に使う「datetime」「time」「calendar」、データファイルに使う「csv」や「json」、ユーザーインターフェースが作れる「tkinter」などのこと：標準モジュール
  • これらはPython環境にすでに用意されているため、importで指定するだけで使うことができる
  • 「おみくじプログラム」で使っていた、「毎回何が出るかわからない数」のことを「random（ランダム、乱数）」という
  • 「choice()」という関数は、リストの中からランダムに1つ選び出すという命令
第1章で出てきた「batteries included（バッテリー付属）」の道具箱が、この標準モジュールです。

✂️ モジュール名を省略する（その1）：as

「モジュール名.関数」と指定して使ったとき、プログラムの中で何度もその関数を実行するような場合、長いモジュール名だと読みにくいため、「import モジュール名 as 省略名」とすることで、モジュール名を省略名で書くことができるようになる

例 
import calendar as cal# calendar を cal という短い名前で使うprint(cal.month(2026,6))

✂️ モジュール名を省略する（その2）：from

「モジュール名.関数名」と指定して使うとき、関数名の前のモジュール名を書かずに済ませる「from モジュール名 import *」という方法もある

  • タートルグラフィックスのプログラムで使っていた方法で、標準ライブラリの「turtle」をインポートするため、本来なら「turtle.shape("turtle")」と書くところを、「from turtle import *」と指定することで、「shape("turtle")」と省略できていた
  • 簡単なプログラムでは省略できて便利だが、プログラムが複雑になってくると、同じ関数名がぶつかってエラーになってしまうこともあるため、注意が必要

📅 時刻を扱うモジュール

「datetime」は日付と時刻を、「calendar」はカレンダーに関する処理を扱うことができるモジュール

プログラム 
import calendarprint(calendar.month(2026,6))# 2026年6月のカレンダー
出力結果
「calendar」というモジュールを読み込んで動かすプログラムのため、保存するファイル名には「calendar.py」以外の名前をつける

自分のファイルを calendar.py という名前にすると、Pythonは本物の calendar モジュールではなく自分のファイルを読み込んでしまうためです。

変数
