コンピューターは、人間の言葉（日本語や英語）をそのままでは理解できません。そこで、コンピューターに「これをやってね」とお願いするための専用の言葉が作られました。それがプログラミング言語です。そして、その言葉で書いた「お願いの手順書」をプログラムと呼びます。
人間 → プログラミング言語 → コンピューター。言語は「通訳さん」のような役目です。

プログラミング言語には、Python・C・Java などたくさんの種類があります。日本語・英語・フランス語…と人間の言葉がたくさんあるのと同じですね。この章では、その中のPythonを紹介します。

✨ Pythonの3つの特長

Pythonが人気なのには理由があります。大きく分けると次の3つです。

1シンプルなプログラム

  • プログラムの「処理のまとまり」を「インデント（字下げ）」を使って書く決まりのおかげで、誰が書いても読みやすいプログラムになる

インデント（字下げ）とは、行のはじめに空白を入れて文字を右にずらすこと。箇条書きのノートで、小見出しの中身を少し右にずらして書くのと同じです。

# もし雨が降っていたら…if 雨が降っている:    傘を持つ# ← 右にずらした行は「もし〜なら」の中身    長ぐつをはく出かける# ← ずらしていない行は、雨でも晴れでも実行
黄色い部分がインデント。「どこからどこまでが1つのまとまりか」が見た目でひと目でわかります。
（説明のため日本語で書いた「イメージ」です。実際のPythonは英語の単語を使います）

Pythonでは、このずらし方がルールとして決まっているので、Aさんが書いても、Bさんが書いても、同じような整った形になります。だから他の人が書いたプログラムでも読みやすいのです。

2ライブラリが豊富

  • Pythonには強力な標準ライブラリが付属しているため、Pythonだけで様々なことができることから、「Pythonには、バッテリーが付属している（batteries included）」ともいわれる
  • 外部のライブラリも充実しており、高速な数値計算や画像処理、機械学習のライブラリなどが様々あるため、人工知能などによく使われている

ライブラリとは、よく使う便利な機能を、誰かがあらかじめ作ってまとめておいてくれた「道具箱」のことです。自分でゼロから作らなくても、道具箱から取り出すだけで使えます。

🔋 標準ライブラリ

Pythonを入れると最初から付いてくる道具箱。
「電池付きのおもちゃ」のように、買ってすぐ遊べる！ これが batteries included（バッテリー付属）と呼ばれる理由です。

🧰 外部ライブラリ

世界中の人が作って公開している、あとから追加できる道具箱。
例：高速な数値計算／画像処理／機械学習　など

機械学習用の道具箱がそろっているから、人工知能を作るときにPythonがよく選ばれるんですね。

3試行錯誤がやりやすい

  • Pythonはプログラムを書いたらすぐに実行できる「インタープリタ言語」
  • 試行錯誤がやりやすい言語なため、初心者にも、新しいものを生み出す開発者にも向いている
  • これに対して、CやJavaなどは「コンパイラ言語」といい、プログラムを実行ファイルに変更するため手間がかかるが、その分実行時の速度が速いという利点がある

試行錯誤とは「ちょっと試す → 結果を見る → 直す」をくり返すこと。これがすぐにできるかどうかは、プログラムの動かし方の違いで決まります。

Pythonは「書いたらすぐ実行」。C や Java は「変換してから実行」。

🗣️ インタープリタ言語（Python）

たとえるなら同時通訳。話したそばから訳してくれるので、すぐ伝わる。

◎ 書いたらすぐ動かせる → 試行錯誤がしやすい

📚 コンパイラ言語（C・Java など）

たとえるなら翻訳本。先に全部を訳して本にするので手間はかかるけど、できあがった本はスラスラ読める。

△ 実行前に変換の手間がかかる
◎ その分、実行時の速度が速い

すぐ試せるPythonは、はじめてプログラミングを学ぶ人にも、新しいものを生み出す開発者にも向いています。

📘 ことばのミニ辞典

プログラミング言語
コンピューターにお願いをするための専用の言葉。
プログラム
プログラミング言語で書いた「お願いの手順書」。
インデント（字下げ）
行のはじめに空白を入れて右にずらすこと。Pythonでは「処理のまとまり」を表す大切なルール。
ライブラリ
便利な機能をまとめた道具箱。最初から付いてくる「標準ライブラリ」と、あとから追加する「外部ライブラリ」がある。
インタープリタ言語
書いたプログラムをすぐに実行できる言語。例：Python。
コンパイラ言語
プログラムを一度「実行ファイル」に変換してから動かす言語。手間はかかるが実行は速い。例：C、Java。
