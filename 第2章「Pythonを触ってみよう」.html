LESSON 3Pythonで計算してみよう

print() は「カッコの中身を画面に表示してね」というお願いです。カッコの中に計算式を書くと、計算した答えを表示してくれます。

書式 
print(ここに表示したいもの)

実行内容と出力結果

入力したプログラム出力結果どういうこと？
print(1+1)21 足す 1
print(100-1)99100 引く 1
print(2*5)102 掛ける 5（掛け算は *）
print(10/5)2.010 割る 5（割り算は /）。答えは小数の形で出ます
print(6//4)16 ÷ 4 ＝ 1.5 の小数部分を切り捨てて 1
print(6%4)26 ÷ 4 ＝ 1 余り 2 の「余り」
出力結果
  • 正しい計算の結果が出力された

計算に使う記号のまとめ

記号計算
+足し算
-引き算
*掛け算
/割り算
//割り算（小数部分を切り捨て）
%割り算の余り
算数の「×」「÷」はキーボードで打ちにくいので、プログラミングでは *（アスタリスク）と /（スラッシュ）を使います。

LESSON 4文字を表示してみよう

数字だけでなく、文字も表示できます。ただし文字を表示するときには、あるルールがあります。

実行内容と出力結果

入力したプログラム出力結果どういうこと？
print(フタバ)エラー
(NameError)		記号で囲んでいないので、Pythonが「フタバって何？」と分からなくなった
print("フタバ")フタバ" " で囲んだので、文字として表示された
print("Hello")Hello英語でも同じ
print("答えは", 10+20)答えは 30,（カンマ）で区切ると、文字と計算結果を並べて表示できる
print("こんにちは')エラー
(SyntaxError)		始まりが " なのに終わりが ' 。左右で記号がちがうので文字の終わりが分からない
print('私は"おはよう"といった。')私は"おはよう"といった。外側を ' で囲んでいるので、中の " はただの文字として表示された
出力結果
  • 文字列を表示するには、「'（シングルクォーテーション）」か「"（ダブルクォーテーション）」で囲む
  • 囲まれていない場合、もしくは両側で違う記号の場合は、エラーが表示される
  • 同じ記号で囲まれていると文字列として認識されるため、2種類を同時に使うこともできる
' や " は「ここからここまでが文字ですよ」という目印のカッコのようなもの。
プログラムの世界では、文字のならびを文字列（もじれつ）と呼びます。

LESSON 5ファイルにプログラムを書いてみよう

ここからは何行かのプログラムをファイルに保存して実行します。保存しておけば、何度でも同じプログラムを動かせます。

👋 あいさつプログラム

  1. 新規ファイルを作る（File メニュー → New File を選択）
  2. プログラムを入力するウィンドウが表示される
  3. プログラムを入力する
    プログラム 
    print("こんにちは、フタバさん。")
print("今日はいい天気ですね。")
  4. ファイルを保存する（File メニュー → Save を選択）
  5. ファイル名に拡張子「.py」をつける
  6. Run メニュー → Run Module を選択で、挨拶を表示してくれる
出力結果
拡張子とは、ファイル名の最後につく「.〇〇」のこと。「.py」は「これはPythonのプログラムですよ」という名札です（例：hello.py）。

🎋 おみくじプログラム

  1. 新規ファイルを作り、プログラムを入力する
    プログラム 
    import random
kuji = ["大吉", "中吉", "小吉", "凶"]
print(random.choice(kuji))
  2. ファイルを保存する
  3. プログラムを実行する（実行するたびに違う結果が表示される）
import random
「ランダム（でたらめに選ぶ）」の道具箱（ライブラリ）を使えるようにする。第1章の「ライブラリ」がさっそく登場！
kuji = [ … ]
4つのくじを [ ] でひとまとめにして、「kuji」という名前の箱に入れる。
random.choice(kuji)
kuji の中から1つをランダムに選ぶ。それを print で表示。
出力結果

⚖️ BMI値計算プログラム

  1. 新規ファイルを作り、プログラムを入力する
    プログラム 
    h = float(input("身長何㎝ですか？"))/100.0
w = float(input("体重何㎏ですか？"))
bmi = w / (h * h)
print("あなたのBMI値は、",bmi,"です。")
  2. ファイルを保存する
  3. プログラムを実行する
    • まず「身長何㎝ですか？」と聞いてくるので、身長を入力しEnter
    • 次に「体重何㎏ですか？」と聞いてくるので、体重を入力しEnter
    • BMI値を計算して表示してくれる
input("…")
「…」と質問を表示して、キーボードで入力された答えを受け取る。
float( )
入力された答えは「文字」なので、計算できる数（小数）に変換する。
h ／ w ／ bmi
身長（m）・体重（kg）・BMI を入れておく名前つきの箱。/100.0 で cm を m に直している。
出力結果
BMI ＝ 体重(kg) ÷ (身長(m) × 身長(m))。プログラムの「bmi = w / (h * h)」は、この式をそのまま書いたものです。面倒な計算もプログラムにすれば一瞬です。

LESSON 6カメで絵を描いてみよう

タートルグラフィックス：画面の中のカメ 🐢 に「進め」「曲がれ」と命令すると、カメが歩いたあとに線が引かれて絵が描けます。カメをまっすぐ進めて「直線」を表示するところから始めましょう。

➖ カメで直線を描く

プログラムを入力して実行する

プログラム 
from turtle import *# カメの道具箱を使えるようにするshape("turtle")# 矢印の形をカメにするforward(100)# 前に100進むdone()# 描き終わり（ウィンドウを開いたままにする）
出力結果
  • 左から右にカメが動いた
  • forward(100)は、前に100進めという意味

⬜ 正方形を描く

プログラムを入力して実行する

「まっすぐ進んで、左に90度曲がる」という行動を4回繰り返して、正方形を描く

プログラム 
from turtle import *shape("turtle")for i in range(4):# 下のずらした行を4回くり返す    forward(100)# 100進む    left(90)# 左に90度曲がるdone()
同じ命令を4回書かなくても、for i in range(4): で「4回くり返して」と書くだけ。
出力結果
スペースはインデントという大事な意味があるものだから取ってはいけない（先頭にスペースがあってもエラーになる）

黄色い部分がインデント（字下げ）です。第1章で学んだとおり、Pythonでは右にずらした行が「くり返しの中身」という意味になります。逆に、ずらす必要のない行の先頭にスペースを入れてもエラーになります。

⭐ カラフルな星を描く

プログラムを入力して実行する

「まっすぐ進んで、左に144度曲がる」という行動を5回繰り返して、星を描く

プログラム 
from turtle import *shape("turtle")col = ["orange","limegreen","gold","plum","tomato"]# 使う5色のリストfor i in range(5):    color(col[i])# i番目の色に変える    forward(200)# 200進む    left(144)# 左に144度曲がるdone()
出力結果
  • プログラム4行目は、「以下の3行を5回繰り返すこと」を意味している
i には、くり返すたびに 0 → 1 → 2 → 3 → 4 と数が入ります。だから col[i] は1回目が "orange"、2回目が "limegreen"…と、毎回ちがう色になります（Pythonでは数を 0から 数えます）。

🌸 カラフルな花を描く

プログラムを入力して実行する

「半径100の円を描いて、左に72度曲がる」（星形のプログラムの6行目と7行目だけを修正）

プログラム 
from turtle import *shape("turtle")col = ["orange","limegreen","gold","plum","tomato"]for i in range(5):    color(col[i])    circle(100)# ← 変更：半径100の円を描く    left(72)# ← 変更：左に72度曲がるdone()
出力結果
  • 半径100の円を描くこと、左に72度曲がることにしただけで、5つの円ができ、花の形になった

📐 曲がる角度で形が変わる！

正方形
90° × 4回 ＝ 360°
ちょうど1周
星
144° × 5回 ＝ 720°
くるっと2周
花
円を描いて 72° × 5回 ＝ 360°
ちょうど1周
プログラムをほんの少し変えるだけで、まったくちがう絵になります。数字を変えて試してみるのがプログラミングの楽しさです！

🎨 もっと複雑な絵を見てみよう

  1. Help メニュー → Turtle Demo を選択すると、タートルのデモ画面が表示される
  2. デモ画面の Examples メニューから例を選択で、左側にプログラムが表示され、START ボタンをクリックで、自動で絵が表示される
