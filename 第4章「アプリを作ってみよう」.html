LESSON 17こんにちはアプリを作る

🙋
はじめて
さん
今までは文字が出てくるだけでしたけど、ボタンがあるような「アプリ」も作れるんですか？
👩‍🏫
先生
作れますよ！ Pythonに最初から付いてくる tkinter（ティーキンター） という道具箱を使います。
  • tkinter：GUIツールキットといい、ウィンドウの上にボタンやラベルを並べて、操作できる画面を作ることができるライブラリ
GUI（ジーユーアイ）とは、ウィンドウ・ボタン・文字など、マウスで操作できる画面のこと。スマホやパソコンのアプリはほとんどがGUIです。

🧱 ラベルとボタンを表示するだけのアプリ

プログラム 
import tkinter as tk root = tk.Tk()# ウィンドウ（土台）を作るroot.geometry("200x100")# 大きさを 横200×縦100 にする lbl = tk.Label(text="LABEL")# ラベル（文字を表示する部品）btn = tk.Button(text="PUSH")# ボタン lbl.pack()# ラベルを配置btn.pack()# ボタンを配置tk.mainloop()# 画面を動かし始める
出力結果
  • まだ部品を並べただけで、ボタンをクリックしたらどんなことをするかは教えていないため、ボタンをクリックしても何も変化しない

👆 ボタンで動くようにする

ボタンをクリックしたら、ラベルに「こんにちは」と表示するアプリ

「こんにちはと表示する関数」を追加して、ボタンがクリックされたらその関数を呼び出すように修正

プログラム 
1import tkinter as tk2 3def dispLabel():4    lbl.configure(text="こんにちは")5 6root = tk.Tk()7root.geometry("200x100")8 9lbl = tk.Label(text="LABEL")10btn = tk.Button(text="PUSH", command = dispLabel)11 12lbl.pack()13btn.pack()14tk.mainloop()
出力結果
  • 3行目で関数を追加し、4行目でラベルの文字を「こんにちは」に変更

🛠️ tkinterの使い方

● ウィンドウを作る

root = tk.Tk()root.geometry("200x100")
  • この数字に合わせて小さくなったり大きくなったりする
"200x100" は「横200 × 縦100」という意味です（単位はピクセル＝画面の点の数）。間の文字は小文字の x（エックス） です。

● ラベルとボタンの作成

lbl = tk.Label(text="LABEL")btn = tk.Button(text="PUSH",command = dispLabel)
  • まだ部品を作っただけで、画面には表示されていない

● 部品の配置

lbl.pack()btn.pack()
  • packの命令を実行した順に、上から配置されていくため、命令した順番で並びが変わる

● メインループ

tk.mainloop()
  • 作った画面がこの命令で動き始める

🔗 ボタンをクリックすると関数が呼び出されるしくみ

btn = tk.Button(text="PUSH", command = dispLabel)

「command = dispLabel」の部分が、ボタンがクリックされたら、dispLabelという関数を実行するという意味

することをあらかじめ関数としてまとめておいて、ボタンを作るときは関数名を指定することで、命令をまとめやすくなる

def dispLabel():    lbl.configure(text="こんにちは")

「ラベルの文字を"こんにちは"に変更する」ということをしており、違うことをさせたいときには関数の中を修正するだけで変えることができる

configureは修正するという意味

ボタンには「押されたらこの関数を呼んでね」と関数の名前だけを渡しておきます。
command には dispLabel と名前だけを書き、( ) は付けません。dispLabel() と書くと、ボタンを押す前に実行されてしまいます。

LESSON 18画像表示アプリを作る

ボタンを押してパソコンの中の画像を選ぶと、ウィンドウに表示してくれるアプリを作ります。

tkinter
ウィンドウを表示する
tkinter.filedialog
ファイルダイアログを使う
PIL.Image
画像を扱う
PIL.ImageTk
画像をtkinterで作った画面上に表示させる
ファイルダイアログとは、「ファイルを開く」を選んだときに出てくる、ファイルを選ぶための小さな画面のことです。
PIL は画像を扱う外部ライブラリです（Pillow という名前でインストールします）。
プログラム 
1import tkinter as tk2import tkinter.filedialog as fd3import PIL.Image4import PIL.ImageTk5 6def dispPhoto(path):7# 画像を読み込む8    newImage = PIL.Image.open(path).resize((300,300))9#そのイメージをラベルに表示する10    imageData = PIL.ImageTk.PhotoImage(newImage)11    imageLabel.configure(image = imageData)12    imageLabel.image = imageData13 14def openFile():15    fpath = fd.askopenfilename()16    if fpath:17        dispPhoto(fpath)18 19root = tk.Tk()20root.geometry("400x350")21 22btn = tk.Button(text="ファイルを開く", command = openFile)23imageLabel = tk.Label()24btn.pack()25imageLabel.pack()26tk.mainloop()
出力結果

💬 コメント文の書き方

プログラムの中の「#」から始まる部分はコメント文です。

# 先頭を#にしてコメントを書く root = tk.Tk() #行の途中に書いた場合は#から改行までがコメント
  • コメント文はプログラムを読みやすくするための「人間向けの説明文」であり、コンピュータはコメント文を無視するため処理には影響しない
  • コメント文だらけになるとプログラムが見にくくなってしまうため、プログラムの意味を少しだけ書くことがコツ

複数行のコメントを「'''（シングルクォーテーション3つ）」か「"""（ダブルクォーテーション3つ）」で囲むことで書くことができる

複数行コメントの書き方 
"""この行はコメントこの行もコメント"""
このページのプログラムに付いている灰色の「# 〜」も、すべてコメント文です。

LESSON 19画像表示アプリのしくみ

LESSON 18 のプログラムを、4つの部分に分けて見ていきましょう。

📥 モジュールのインポート

1import tkinter as tk2import tkinter.filedialog as fd3import PIL.Image4import PIL.ImageTk

🪟 画面を作る部分

19root = tk.Tk()20root.geometry("400x350")21 22btn = tk.Button(text="ファイルを開く", command = openFile)23imageLabel = tk.Label()24btn.pack()25imageLabel.pack()26tk.mainloop()
  • アプリの画面を作っている部分
  • ウィンドウを用意して、ファイルを開くボタンを作って配置
  • 「command = openFile」でボタンがクリックされたらファイルダイアログを開く関数を実行
  • 画像を表示するラベル（imageLabel）も作っている

📂 ファイルを開くopenFile()関数

14def openFile():15    fpath = fd.askopenfilename()16    if fpath:17        dispPhoto(fpath)
  • 「fd.askopenfilename()」は、ファイルダイアログを出す関数
  • ファイルダイアログが出ている間は、ここの行で止まった状態になり、ファイルを選んで［Open］［Cancel］ボタンをクリックすると、選んだファイル名がfpath変数に入ってきて、次の行へ進んでいく
  • ［Cancel］ボタンを選んだ場合、変数の中に空っぽな値として入ってくるため、ファイルが選択されなかったことがわかる
  • ファイル名があるかどうかを「if fpath:」で調べているため、もしファイル名が入っていたら、その画像を開くdispPhoto(fpath)を実行するが、なかったら何もしない
「if fpath:」のように、比較の記号を使わずに変数だけを書くと、「中身が入っていれば True、空っぽなら False」として扱われます。

🖼️ 画像を表示するdispPhoto()関数

6def dispPhoto(path):7# 画像を読み込む8    newImage = PIL.Image.open(path).resize((300,300))9#そのイメージをラベルに表示する10    imageData = PIL.ImageTk.PhotoImage(newImage)11    imageLabel.configure(image = imageData)12    imageLabel.image = imageData
  • 画像を表示する関数
  • まず、画像ファイルを開いて、300x300（ピクセル）にリサイズする
  • 次にその画像をラベルに表示できるデータに変換して、ラベルに表示させている
ラベルは文字だけでなく、画像も表示できる部品です。configure(image = …) で、ラベルの中身を画像に入れかえています。

📏 関数を書く順番に注意

  • プログラムは上から順番に実行していくため、ボタンを作るところで「command = openFile」と書くなら、openFile関数はそれより上に書かなければならない
  • さらにopenFile関数の中で「dispPhoto(fpath)」を呼び出すなら、dispPhoto関数はopenFile関数より上に書いておかなければならない

LESSON 20画像表示アプリを改造しよう

ファイルを開く処理や、アプリの画面などの基本部分はそのままで、画像を作る8行目を修正するだけで、いろいろな画像に変身させられます。

⚫ 改造1：モノクロ画像に変換

「.convert("L")」で、カラー画像をモノクロ（グレースケール）に変換すると、読み込んだ画像がモノクロで表示されるようになる

プログラム（6〜8行目だけ。ほかは LESSON 18 と同じ） 
6def dispPhoto(path):7# 画像を読み込んでグレースケールに変換する8    newImage = PIL.Image.open(path).convert("L").resize((300,300))
出力結果
  • 「関数名()」が3つつながっている
  • pathで指定された画像ファイルを開く（open）→その画像をグレースケールに変換する（convert）→300x300の大きさに変換する（resize）という命令を順番に行っている
📂 open
画像を開く▶ ⚫ convert("L")
モノクロに▶ 📐 resize((300,300))
300×300に
グレースケールとは、白・黒・灰色の濃さだけで表した画像のこと。"L" はその形式を表す記号です。

🟫 改造2：モザイク画像に変換

画像を作る8行目を修正するだけ

画像をグレースケールに変換してから、解像度を一度下げて、再び大きくリサイズすることで、モザイク画像にしている

プログラム（6〜8行目だけ。ほかは LESSON 18 と同じ） 
6def dispPhoto(path):7# 画像を読み込んで、モザイクに変換する8    newImage = PIL.Image.open(path).convert("L").resize((32,32)).resize((300,300),resample=0)
出力結果
📂 open▶ ⚫ convert("L")▶ 🔽 resize((32,32))
小さくして情報を減らす▶ 🔼 resize((300,300), resample=0)
ぼかさずに引き伸ばす
  • ぼかしをかけずにカクカクの画像にするために「resample=0」と指定しており、指定することで、32x32に縮小した粗い画像をなめらかにすることなく、そのまま引き伸ばすため、モザイク効果が生まれる
  • 「pathで指定された画像ファイルを開く（open）→その画像をグレースケールに変換する（convert）」をしたあと、一度「32x32（ピクセル）まで小さく変換（resize）」してから「300x300（ピクセル）の大きさに変換（resize）」しており、これはまず、画像を小さくすることで情報量を減らし、その画像をぼかすことなくそのまま拡大すれば、モザイク状の画像になるというしくみ
32 を 16 にするとモザイクがもっと粗く、64 にすると細かくなります。数字を変えて試してみましょう！
