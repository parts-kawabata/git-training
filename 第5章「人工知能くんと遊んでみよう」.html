LESSON 21人工知能の歴史

人工知能は1950年代から研究されている。これまでに大きなブームが3回ありました。

第1次ブーム
🧩
推論探索システム
  • 計算がよくでき、迷路やパズルを解くことができた
  • 「知識」がないため、人間の質問には答えることができなかった
第2次ブーム
👨‍⚕️
エキスパートシステム
  • 「専門家（エキスパート）の知識」をコンピュータに入れたら質問に答えられると考えた
  • 例）患者さんの症状を入れると病名を教えてくれるシステム
  • 用意した知識で調べるため用意していない知識については答えられず、ちゃんと答えられるようにするには開発者が膨大な知識を用意しなければならない
第3次ブーム（いま）
🧠
ディープラーニング
  • 機械学習の一種のディープラーニング
  • インターネットを使ってデータを集めることで集めやすくなり、大量のデータを与えられるため、精度のよい人工知能を作ることができる
第2次ブームまでは「人間が知識を教えこむ」やり方でした。第3次ブームでは「たくさんのデータからコンピュータ自身が学ぶ」やり方に変わったのが大きなちがいです。

LESSON 23機械学習で数字を当てよう

機械学習：コンピュータにたくさんのデータを与えてコンピュータ自身が学習する方法で、主に3種類ある

👩‍🏫
教師あり学習
たとえるなら
答え付きの問題集で勉強
  • 「問題と答えのペア」を大量に与えて特徴を学習させる方法で、答えのことを「教師データ」と呼ぶため「教師あり学習」という
  • 新しいデータを与えたとき、その特徴からそれが何なのかを答えることができ、文字認識や音声認識、翻訳などで使われている
🧺
教師なし学習
たとえるなら
似たもの同士の仲間分け
  • 大量のデータから似たデータをまとめて、特徴を抽出したり、グループ分け（クラスタリング）したりするときに使う方法
  • 答えのない大量のデータを調べるため、答えを見つけるための学習ではない
🏆
強化学習
たとえるなら
ごほうびで上達
  • 試行錯誤させて、良い結果が出たときに「報酬」を与えて強化していく学習方法
  • よりよい方法を見つけるための方法で、ロボットの制御や将棋や囲碁などで使われている

✍️ 手書きの数字を認識するアプリ

  • 特徴を見て「それが何なのか」を答えるもの（教師あり学習）
  • 大量の「数字の画像」と「それが何の数字か」のペアを与えて、「数字の特徴」を学習させる

🔢 数字のデータを見てみよう

sklearnにあるデータを読み込んで、そのデータを表示、「データの個数」と「1つ目の画像データ」と「1つ目の数字が何なのか」を表示

プログラム 
import sklearn.datasets digits = sklearn.datasets.load_digits()# 数字の画像データを読み込む print("データの個数=",len(digits.images))print("画像データ=",digits.images[0])print("何の数字か=",digits.target[0])
出力結果
  • データの個数は1797個
  • 画像データは数字のリストで表示され、このデータは8x8の数値のリストでできている
  • 濃淡を数値で表示しており、数字が小さいほど薄く、大きいほど濃くなる（0が一番明るい白、16が一番暗い黒）
上の出力結果の数値を、濃さに合わせて色をぬってみると…「0」の形が見えてきます！

matplotlibというライブラリを使ってこの数値データを画像化する

  • 画像化すると「0」だということがわかる

🎯 画像ファイルから数字を予測するプログラム

データを読ませて数字を学習させる→「新しい数字の画像」（ここでは数字の2の画像）を見せて、何の数字かを予測させる

プログラム 
1import sklearn.datasets2import sklearn.svm3import PIL.Image4import numpy5 6# 画像ファイルを数値リストに変換する7def imageToData(filename):8#画像を8x8のグレースケールに変換9    grayImage = PIL.Image.open(filename).convert("L")10    grayImage = grayImage.resize((8,8),PIL.Image.Resampling.LANCZOS)11# 数値リストに変換12    numImage = numpy.asarray(grayImage, dtype = float)13    numImage = 16 - numpy.floor(17 * numImage / 256)14    numImage = numImage.flatten()15 16    return numImage17 18# 数字を予測する19def predictDigits(data):20# 学習用データを読み込む21    digits = sklearn.datasets.load_digits()22# 機械学習する23    clf = sklearn.svm.SVC(gamma = 0.001)24    clf.fit(digits.data, digits.target)25# 予測結果を表示する26    n = clf.predict([data])27    print("予測=",n)28 29# 画像ファイルを数値リストに変換する30data = imageToData("2.png")31# 数字を予測する32predictDigits(data)
出力結果
  • 学習したため予測できた
「2.png」は、プログラムと同じフォルダに置いた手書きの「2」の画像です。

LESSON 24数字を当てるプログラムのしくみ

LESSON 23 のプログラムは、2つの関数でできています。

🔄 imageToData()関数の説明

  • まず、画像データは数値リストに変換する必要がある
  • 読み込んだ画像ファイルをグレースケールのモザイク画像に変換し、numpyを使って数値のリストに変換する
# 画像ファイルを数値リストに変換するdef imageToData(filename):#画像を8x8のグレースケールに変換    grayImage = PIL.Image.open(filename).convert("L")    grayImage = grayImage.resize((8,8),PIL.Image.Resampling.LANCZOS)# 数値リストに変換    numImage = numpy.asarray(grayImage, dtype = float)    numImage = 16 - numpy.floor(17 * numImage / 256)    numImage = numImage.flatten()     return numImage
🖼️ 画像ファイル▶ ⚫ 8x8のグレースケール
convert / resize▶ 🔢 8x8の数値リスト
255（白）〜0（黒）▶ 🔁 0〜16に変換
0（白）〜16（黒）▶ ➖ 1列に並べる
64個の数値
  • 初めの2行で与えた画像を8x8のグレースケールに変換
  • 画像を8x8にまでリサイズするときに、小さくしても自然な画像になるようにアンチエイリアスを指定している
  • 最初の「numpy.asarray(grayImage, dtype = float)」で、画像を8x8の数値リストに変換している
  • 学習させたいデータは0～16の濃淡でできた1列の数値リストであり、このままだと255～0の濃淡データになってしまうため、「16 - numpy.floor(17 * numImage / 256)」で0～16の濃淡に変換して、次の「flatten()」で1列の数値リストに変換している
  • どんなデータに変換されるのか見たいときは、「numImage =」の各行の次に「print(numImage)」を書き足せば、変更の様子を見ることができる
  • imageToData()関数では、「与えた画像」を「予測に使える数値リスト」に変換している
画像の色変換前の数値16 - floor(17 × 数値 ÷ 256)変換後
⬜ 白25516 - floor(16.93…) ＝ 16 - 160
◻️ 灰色12816 - floor(8.5) ＝ 16 - 88
⬛ 黒016 - floor(0) ＝ 16 - 016
画像は「白が大きい数（255）」、学習用データは「黒が大きい数（16）」と、数え方が逆さまです。そこで計算で向きと範囲をそろえています。floor は小数点以下を切り捨てる命令です。

🧠 predictDigits()関数の説明

  • 変換した数値リストから何の数字か予測する
# 数字を予測するdef predictDigits(data):# 学習用データを読み込む    digits = sklearn.datasets.load_digits()# 機械学習する    clf = sklearn.svm.SVC(gamma = 0.001)    clf.fit(digits.data, digits.target)# 予測結果を表示する    n = clf.predict([data])    print("予測=",n)
プログラム意味
def predictDigits(data):何の数字か予測する関数
clf = sklearn.svm.SVC(gamma = 0.001)学習の準備をする
clf.fit(digits.data, digits.target)データを使って学習
n = clf.predict([data])何の数字か予測
📚 load_digits()
学習用データを読み込む▶ 🤖 SVC()
学習の準備▶ ✏️ fit()
データを使って学習▶ 🎯 predict()
何の数字か予測
  • 「load_digits()」関数で、学習用データを読み込み、「clf.fit()」関数で数字画像（data）と、それが何の数字か（target）を渡して学習させる
  • 最後に予測する画像の数値リストを渡して、「それが何の数字なのか」を予測させる
SVC は機械学習のやり方（アルゴリズム）の1つです。clf は「分類するもの（classifier）」を縮めた変数名です。

LESSON 25数字を認識するアプリ「チノ」を作ろう

手書きの数字の画像ファイルを指定すると、その画像に書かれている数字を認識して答えてくれるアプリ「チノ」

「いろいろな画像を読み込んでモザイク画像を表示させるアプリ」と「画像ファイルから数字を予測するプログラム」を組み合わせる

🪟 いろいろな画像を読み込んでモザイク画像を表示させるアプリ部分

プログラム 
import tkinter as tkimport tkinter.filedialog as fdimport PIL.Imageimport PIL.ImageTk # 画像ファイルを数値リストに変換するdef imageToData(filename):# 画像を8x8のグレースケールに変換    grayImage = PIL.Image.open(filename).convert("L")    grayImage = grayImage.resize((8,8),PIL.Image.Resampling.LANCZOS)# その画像を表示する    dispImage = PIL.ImageTk.PhotoImage(grayImage.resize((300,300),resample=0))    imageLabel.configure(image = dispImage)    imageLabel.image = dispImage # ファイルダイアログを開くdef openFile():    fpath = fd.askopenfilename()    if fpath:# 画像ファイルを数値リストに変換する        data = imageToData(fpath) # アプリのウィンドウを作るroot = tk.Tk()root.geometry("400x400") btn = tk.Button(root, text="ファイルを開く", command = openFile)imageLabel = tk.Label() btn.pack()imageLabel.pack() tk.mainloop()
  • ファイルダイアログを開くopenFile()関数の中では、ファイルダイアログで画像ファイルが選ばれたら、画像ファイルを数値リストに変更するimageToData()関数を呼び出す

8x8 に縮めた画像を、第4章のモザイクと同じ resample=0 で 300x300 に引き伸ばして表示しています。人工知能くんには、こんなに粗い画像が見えているんですね。
